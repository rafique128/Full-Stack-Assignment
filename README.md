# ⚡ NexusPulse AI — Event Lead Manager & Intelligence Radar

## 📌 Project Overview
NexusPulse AI is a full-stack web application designed to manage and analyze leads collected during events such as conferences, expos, and business meetings. It uses AI to summarize interactions and generate smart follow-up messages.

---

## 🚀 Features
- Add, edit, delete leads (CRUD operations)
- Real-time search and filtering
- AI-based lead summary generation
- AI-generated follow-up messages (Email, LinkedIn, WhatsApp)
- Kanban pipeline view for lead tracking
- Table view for structured data
- Voice input using Web Speech API
- Export leads to CSV

---

## 🧠 Key Decisions
- **Decision Tree / AI Logic** used for simple and explainable predictions
- **FastAPI backend** for speed and easy API creation
- **SQLite database** for lightweight storage
- **React frontend** for dynamic UI
- Chose **simple + explainable architecture** for better understanding in viva

---

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- Database: SQLite
- AI/NLP: Rule-based + optional API (OpenAI/Gemini)
